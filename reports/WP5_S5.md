## Summary
- Built `v2x/l4.py`: xgboost on 27 plausibility features of L1-L3 (per message: L2 residuals, NIS, CUSUM-hi, beacon rate; trailing 10-message window aggregates; birth density; 2 track descriptors). NOT used: raw position, speed, sender id, time, kf_cusum_lo. Tests: 168 pass (8 new).
- Training: VeReMi train without types 6, 12, 17 (also removed from validation and from neighbour features, asserted). 8 configs on validation: all within 90.8-91.1% mean detection (plateau); chosen d5_mcw1, 120 trees. Threshold: genuine val 1%, tie-safe. Test scored once.
- HEADLINE (VeReMi test, message level, 1% budget): L4 alone mean detection seen-16 91.3% (deployable L1+L2+L3 union 75.6%), FA genuine 1.1%, genuine senders with >= 3 alarms 1.8% (union 10.5%). Harness L1+L2+L3 78.1% -> L1+L2+L3+L4 91.5% mean over 19 classes (FA 1.1% -> 1.2%); pooled AUC 0.893 -> 0.968.
- UNSEEN types (never in train / selection / combiner): class 6 ConstSpeedOffset L4 100.0% vs union 99.1% (no gain, sibling 5 seen); class 17 DataReplaySybil 91.9% [90.3, 93.4] vs 46.4% [42.5, 50.0]; class 12 DelayedMessages 100.0% vs 48.2% (artefact, see below, not claimed).
- Leakage checks. (a) gain: cusum_hi 55.5% (physical state, dominant; implied_speed 12.7, w_pos_speed_mean 12.2, pos_speed 8.5). (b) ablations: no time/track features 91.2% (seen), residuals only (no rate, birth, time) 91.2%: unchanged. (c) shuffled labels: test AUC 0.475 but detection 4.1% pooled at 1.1% FA (my bound was 2%): NOT MET; the noise model's score tail picks outlier rows, which attacks are more often.
- RED FLAG (post-hoc diagnostic, tools/WP5_S5_diag.py, same saved model and same test rows, nothing selected on it): the gain on classes 9, 12 (placeholder), 17, 18, 19 is a "zero residual vector" shortcut. (i) Frozen rows (message repeats the previous position exactly): 0.0% of genuine VeReMi rows, 16.0% of attack rows; L4 flags 100% of them. Genuine Tampa has 10-21% such rows (standing vehicles): the signature is a VeReMi simulation property, the same one for which kf_cusum_lo was dropped. (ii) First messages of tracks (all residuals 0 by construction): L4 flags 100% of the 3,873 genuine ones; they are 84.3% of all its genuine false alarms (scored genuine rows: FA 0.2%). Classes 18/19 (99.7-100% first messages) are credited 100% only because every new identity alarms.
- Scored rows only (message has a predecessor and moved; 68.5% of attack rows): headline L4 / diagnostic L4 retrained on scored rows / baseline union (re-thresholded, 1%): seen classes 83.0% / 83.5% / 82.7%; unseen 6 and 17: 87.4% / 98.2% / 59.9%; class 17 scored rows 74.8% / 96.3% / 19.9%; class 6 100 / 100 / 99.8. So the honest value of L4 is: equal to the physics on seen classes, a real gain on the unseen replay-Sybil class 17 (learned from siblings 11, 16), none on 2 (3.1%) and 9 (2.0% on scored rows). Diagnostic model FA on scored genuine test rows 1.6% (val-test shift; baseline 1.0%).
- Class 12: with the full model 100% (placeholder rows 100%, after-jump rows 100%); without memory features 53.3% = placeholder rows 100% + after-jump rows 2.8%. The placeholder detection is the frozen shortcut, the after-jump detection is CUSUM memory: no delay detection is claimed.
- Tampa (illustration, 3 test vehicles, 2 attackers/type): the VeReMi-trained model does not transfer as is. Probability scale: at the VeReMi threshold FA on genuine Tampa is 100% (beacons at 10 Hz vs 1 Hz put rate / window features out of range; residual-only variant 16.2% FA). Re-thresholded on Tampa genuine val (1%): mean detection 77.6% at FA 0.3% [0.2, 0.5] (baseline union 71.3% at 3.0%), residual-only 71.7% at 0.0%; unseen 6 and 17: 55.1% (union 64.2%); StaleReplay 0% (no freshness feature). Test AUC 0.904 (shuffled-label model 0.736; its mean detection 27.2% = what outlier-ness alone gives). No retraining on Tampa. Harness L1+L2+L3 69.2% -> +L4 72.2% pooled detection (both FA 2.8%).
- Acceptance: 1 MET; 2 MET (1.1% / 1.2%); 3 MET (+13.4 points); 4 MET numerically (96.0% vs 72.8%, >= 50%) but see the red flag; 5 PARTIAL (b MET, a dominant physical state, c NOT MET). Pre-registered expectations: E1 above range (91.3 vs 80-90), E2 met, E3 not (91.9 vs 40-70, first-message flood), E4 half (no-memory 53.3 not < 15, after-jump 2.8), E5 not (9: 79.3%, frozen), E6 not (A2 loses nothing: zero-vector shortcut survives), E7 not (Tampa drop only 14.6 points at the Tampa threshold).
