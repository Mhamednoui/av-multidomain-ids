# Datasets

The datasets are not part of this repository. Download them from their authors
and place them here with this layout:

```
data/
├── CICIDS2017_sample.csv
├── CICIDS2017_sample_km_test.csv
├── CICIoV2024/
│   └── decimal/
│       ├── decimal_benign.csv
│       ├── decimal_DoS.csv
│       ├── decimal_spoofing-GAS.csv
│       ├── decimal_spoofing-RPM.csv
│       ├── decimal_spoofing-SPEED.csv
│       └── decimal_spoofing-STEERING_WHEEL.csv
├── AV-GPS-Dataset/
│   ├── AV-GPS-Dataset-0.csv
│   ├── AV-GPS-Dataset-1.csv
│   ├── AV-GPS-Dataset-2.csv
│   └── AV-GPS-Dataset-3.csv
└── Depth/
    ├── 2011_09_26_drive_0001_sync/2011_09_26/2011_09_26_drive_0001_sync/velodyne_points/data/*.bin
    └── 2011_09_26_drive_0015_sync/2011_09_26/2011_09_26_drive_0015_sync/velodyne_points/data/*.bin
```

## Where to get them

| Folder / file | Source |
|---|---|
| `CICIDS2017_sample.csv` | sampled CICIDS2017 subset from the MTH-IDS repository: https://github.com/Western-OC2-Lab/Intrusion-Detection-System-Using-Machine-Learning (folder `data/`). Full dataset: https://www.unb.ca/cic/datasets/ids-2017.html |
| `CICIDS2017_sample_km_test.csv` | z-score-normalised version of the same 56,661 rows, used for testing and for the simulator. It is not regenerated by a script in this repository. |
| `CICIoV2024/` | https://www.unb.ca/cic/datasets/iov-dataset-2024.html (use the `decimal` CSV files) |
| `AV-GPS-Dataset/` | AV-GPS-Dataset by Abrar et al., released with "GPS-IDS" (arXiv:2405.08359) |
| `Depth/` | KITTI raw data, drives `2011_09_26_drive_0001` (108 scans) and `2011_09_26_drive_0015` (297 scans), Velodyne points: https://www.cvlibs.net/datasets/kitti/raw_data.php |

Respect each dataset's licence. KITTI is CC BY-NC-SA 3.0 (non-commercial).
