## 2026-11-03 S3 (LiDAR) pre-registration of the candidate grid and the selection rule (written BEFORE any combiner result; raw statistics are being built)

Material: V31 train 13 drives + V31_val 10 drives, all clean scans (23 drives, scans i >= 1 have L2c / L2d); attacks only on the 10 V31_val
drives: the S4 set (9 kinds, scans i % 3 == 1, seeds [83, drive, i], attacked scan vs CLEAN previous scan) and persistent PointDrop episodes
(3 per drive = 30, 30 scans each, seeds [101, drive]; fixed sector / fraction, fresh thinning each scan; step 1 vs the clean previous
scan, later steps vs the attacked previous scan). Statistics: lidar/fast.py (identical to v3 for L1, L2c, L2d; L2a tiles from voxel-0.1
clustering, "v3.1 flag" - the exact v3 clustering costs 2.4 s on dense scans and is the main reason for 1.8 s per scan; equivalence of the
voxel tiles checked on a sample, see below).

Evaluation protocol (honest FA): out-of-fold clean scores of the 23 drives (L2a intensity model refitted without the drive, leave-one-drive-out);
for a V31_val drive d the whole stack (ranks, per-layer thresholds) is fitted on the OOF scores of the other 22 drives and judged on d: clean FA
= pooled alarm rate of the clean scans of the 10 V31_val drives (and worst drive); detection = pooled over the 10 drives, bootstrap CI over drives
(B = 2000, seed 31). Budget B = 1 % total (nominal).

Baseline ("v3 rule"): max of the 4 ECDF ranks, threshold 1 % of the max statistic (lidar.combine.Stack("max")), L2c = miss_w20, L2d = app_cc + fix_tot,
L2a = int_hi, int_lo, cnt_int_hi, cnt_int_lo, L1 = L1Union - the same code path, same OOF protocol. The literal frozen v3 domain (thresholds from its
own 16-drive reference) is run on a sample of V31_val scans to show that the voxel L2a and the v3 rule match v3 (regression, reported).

Candidates (all label-free in their thresholds; V31_val attack labels only select among these listed candidates, G9). Union combiner with per-layer
budgets: alarm if any r_i >= tau_i, tau_i = tie-safe b_i quantile of the OOF reference ranks of layer i, sum b_i = B; stack statistic
= max_i (r_i - tau_i) + 1 (monotone; score = its ECDF on the reference). Budget vector family with ONE tuned parameter alpha = share of B given to L2c;
L1, L2a, L2d share the rest equally ((1 - alpha) / 3 each):
- alpha in {0.25 (= v3 "split"), 0.40, 0.55, 0.70, 0.85}
- L2c statistic s in {miss_w20 (v3), miss_w10, miss_g20, miss_z20, u = rank-max(miss_w20, miss_z20)}
- W0 water-filling (zero tuned parameters, label-free): start with b_i = B / 4; a layer whose achievable FA at its tie-safe threshold is below b_i
  keeps only that FA and the unused budget is shared equally by the other layers; repeat until stable.
Total 5 x 5 + 1 = 26 candidates plus the v3 rule (M0) and the v3 "split" (alpha = 0.25, s = miss_w20).

Selection (objective on V31_val, in this order):
1. feasible = LODO clean FA in [0.5, 1.5] % AND for every attack kind in the 9 listed (headline + comparison) detection >= M0 - 2 points (paired, same scans).
2. among feasible: maximise PointDrop per-scan detection; candidates within 0.5 points of the best: G8 order (fewer tuned parameters = W0, then alpha closer
   to 0.25, then s = miss_w20, then alphabetical).
3. If no candidate is feasible: relax rule 1 for the kind that blocks, report NOT MET for L4, and choose by rule 2 on the largest feasible set; the
   unmet rule is stated in the report. A second round (e.g. an extra L2c statistic) is allowed only on V31_val and is logged with its reason.
L3 acceptance: selected candidate PointDrop per-scan >= 70 % at the 1 % budget and 3 s episode detection >= 80 % (v2 rolling log-odds rule on the
selected stack score; threshold = 99th percentile of the rolling statistic over clean reference windows, windows of 30 scans, 10-scan roll; 30 episodes).
L1 speed (ms per scan): measured on the streaming domain object (lidar/domain31.py) on >= 1,000 V31_val clean scans, one core; median <= 100 ms,
p99 <= 250 ms; also reported while the other worker runs (machine load stated). L2: stream == batch on all V31_val scans (domain fitted on all 23
clean drives, batch = records of tools/WP8_S3_build.py scored with the same fitted objects): 0 alarm mismatches, max |score diff| <= 1e-9.
Voxel equivalence (information for L4, the L2a layer changes with the flag): on 150 V31_val scans the tile tables of the exact v3 clustering and
of the voxel clustering give L2a raw scores within a stated tolerance and IntensitySpoof detection within 2 points (paired).

### Method (new module crossdomain/blame31.py; v3 files untouched; version flag = which blame function the caller passes)
Fault isolation by hypothesis scoring on a CHANNEL graph (Preparata et al. 1967 system-level diagnosis with costs; structured residuals, Gertler 1998). Nodes are measurement channels; each belongs to
a sensor (domain):
- K: gps{gps_v, gps_lat}, lidar{lidar_v, lidar_lat, lidar_yaw}, can{can_v}, imu{compass, gyro, ins_v}. Edges = the 7 frozen v3 cross edges: (gps_v, lidar_v), (gps_v, can_v), (lidar_v, can_v),
  (gps_lat, lidar_lat), (compass, lidar_yaw), (compass, gyro), (gyro, lidar_yaw); blame-only inertial edges (gps_v, ins_v), (lidar_v, ins_v), (can_v, ins_v) (candidate A3 only).
- C: gnss{gnss_vel, gnss_pos}, can{can_v, wheel_v}, imu{gyro}. Edges = the 6 frozen v3 edges: gnss-can speed (gnss_vel, can_v), gnss-wheel speed (gnss_vel, wheel_v), can-wheel speed (can_v, wheel_v),
  gnss-can pspeed (gnss_pos, can_v), gnss-wheel pspeed (gnss_pos, wheel_v), gnss-imu yaw (gnss_vel, gyro) (the bearing is a Doppler-velocity quantity).
- Edge state per tick: alarm (the cross layer's own per-edge alarm), agree (observed, not alarm), unobserved. States are LATCHED inside an alarm episode (an edge that alarmed earlier in the
  episode stays alarm, episode = alarm ticks with gaps <= 15 ticks): evidence accumulates, no per-tick flicker; parameter-free.
- Hypothesis H = set of faulty channels (|H| <= 3). cost(H) = sum over sensors touched by H of the sensor cost + 0.5 per additional faulty channel of an already faulty sensor
  + 6 per alarm edge with no faulty endpoint + 3 per agree edge with exactly one faulty endpoint + 0.5 per agree edge with both endpoints faulty (a coordinated attacker produces a consistent lie).
  The best hypothesis decides when the best hypothesis on any OTHER domain set is >= 1.0 more costly (a log-odds margin); equal-cost hypotheses on different domain sets give undecided. The blamed domain of
  a multi-domain hypothesis is its first domain in attack-surface order (gps, can, lidar, imu). No alarm edge: no blame.
- Sensor costs. A1 (no prior): all 3.0. A2 and A3 (prior fixed a priori from the attack surface, never tuned): gps 2.0 (GNSS spoofing needs only a radio), can 3.0 (bus access / ECU), lidar 4.0
  (odometry corruption needs the sensor or a software fault), imu 5.0 (physical access). These constants are the same for K and C.
- Inertial edges (A3, K): accelerometer a = OXTS af (10 Hz) + simulated sensor noise N(0, 0.05 m/s^2) white per sample + per-run constant bias N(0, 0.01 m/s^2) (seeds [42, 31, 1, drive, phase]; a conservative
  MEMS grade, stated as an assumption: the KITTI af itself is much cleaner). Per source s in {gps, lidar, can}: u_s(k) = s(k) - V(k), V = cumulative integral of a on the 1 Hz grid (interval sums of the
  trapezoid). Anchor of an episode = ticks [a, a+2] with a = max(0, first alarm tick - 12): D_s(k) = mean(u_s over the last 3 ticks) - mean(u_s over the anchor ticks). The inertial edge (s, ins) alarms when
  |D_s(k)| >= tau_ins * sigma_s(k - a), sigma_s(delta) = robust sd (1.4826 MAD) of D_s on pseudo-episodes of the clean TRAIN runs (every anchor, bins of delta), tau_ins = max(3.5, 99.9th percentile of |D/sigma| on
  the clean TRAIN runs). Inside an episode only; latched like the other edges. Never used for detection (B4).
- Candidates: V3 (v3 domain rule, the reference); A1 (channel graph, latched, equal costs); A2 (A1 + attack-surface prior); A3 (A2 + inertial edges; identical to A2 on C).
- Selection: a candidate PASSES if B1, B2, B3, C3 and B4 hold on V31_val (point estimates). Choose the simplest passing candidate (A1 < A2 < A3). If none passes: the candidate with the highest number of rules met,
